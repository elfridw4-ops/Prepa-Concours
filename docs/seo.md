# Stratégie SEO — Prépa Concours

## Optimisations Techniques
- Mise en place du `manifest.webmanifest`.
- Meta tags Open Graph (Titre, Description, Image).
- Sémantisation HTML (Section, h1, h2, Header, Main).
- Performance optimisée (Service Worker, mise en cache).

## Mots-clés
- **Principaux** : Prépa concours Bénin, Terminale D, Terminale C, Maths Physique, Exercices Concours, Export PDF LaTeX.
- **Secondaires** : Révision baccalauréat, École d'ingénieurs Bénin, Tuteur IA, Préparation scientifique, Dictée vocale continue, Geste retour Android PWA.

## Structure de Pages
- **Landing Page** : Présentation, FAQ, CTA (Appel à action).
- **Dashboard** : Vue programme, bilan, progression (protégé par authentification/clé API).

## Exemples SEO
- **Meta Title** : Prépa Concours Bénin | Révision Maths & Physique Terminale
- **Meta Description** : Coach de haut niveau pour les élèves de Terminale (D/C). Maîtrisez les Maths et la Physique pour réussir vos concours d'entrée aux grandes écoles.

## Bonnes pratiques
- Mise à jour régulière des contenus.
- Performance de chargement (Core Web Vitals).
- Utilisation efficace des balises Hn pour structurer le contenu.
