# Charte Graphique — Prépa Concours

## Logo
- **Usage** : Application, Favicon, Touch Icons.
- **Référence** : Logo iconographique moderne, abstrait et géométrique.

## Couleurs
- **Couleur principale (Dark Mode)** : `#0f172a` (Fond sombre, Slate 950)
- **Couleurs d'accent** :
  - `Blue-400` : `#60a5fa`
  - `Green-400` : `#4ade80`
  - `Indigo-400` : `#818cf8`

## Typographie
- **Titres** : "Inter" (Sans-serif), font-black, tracking-tight.
- **UI/Texte** : "Inter" (Sans-serif), font-medium.
- **Mono** : "JetBrains Mono" pour les éléments techniques intégrés.

## Iconographie
- `lucide-react` (icons cohérentes avec l'interface minimaliste).

## Interface UI
- **Composants** : Bords arrondis (rounded-xl, rounded-2xl), bordures fines (border-gray-800).
- **Espacement** : Système de grille flexible et réactif (Tailwind CSS).
